# Privacy Policy

**Dark Mode for Artificial Analysis — Unofficial** does not collect, store, sell, share, or transmit personal data, browsing history, website content, form data, analytics, or identifiers.

The extension runs only on `https://artificialanalysis.ai/*`. It consists solely of two CSS files that the browser applies to that site. It contains no JavaScript, so it cannot read page content, observe navigation, or persist or send anything.

The extension contains no tracking, advertising, remote code, external API calls, background service worker, account system, or configurable storage.

Artificial Analysis itself remains governed by its own privacy policy. This independent extension is not affiliated with Artificial Analysis.

Last updated: September 6, 2026.
